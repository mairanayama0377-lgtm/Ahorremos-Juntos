# Ahorremos-Juntos
Ahoraria Emprende es una página interactiva que permite organizar ingresos y gastos, crear metas de ahorro y visualizar las finanzas personales. También ofrece ideas de emprendimiento, videos educativos y herramientas para crear un plan de negocio. Su diseño es juvenil, colorido y fácil de usar, con animaciones y modo oscuro.
